# ЦДБ — общая работа с пациентами

Главная: экономика, маркетинг и клиентская база. Экономика сохранена. marketing.html и clients.html открывают подключение к закрытому iamkurakov/centrdb-data. После ввода ключа и имени сотрудника база читается автоматически, результаты записываются обратно. Ни загрузка, ни перенос файлов для повседневной работы не нужны.

Исходная база: data/client-base-2026-11-02.json. Общие результаты: work/patient-workspace.json. Это разные файлы закрытого репозитория. Публичный сайт содержит только код и вымышленные примеры. Ключи и реальные пациентские данные нельзя включать в публичную сборку.

Соединение GitHub выполняется из браузера по HTTPS напрямую с api.github.com. Токен хранится в памяти, по выбору пользователя также в sessionStorage этой вкладки. В исходники не попадает. Доступ этого чата к GitHub не передаёт сайту ключ. Первый вход с действительным ключом обязателен.

Проверены 8 сценариев с подменённым GitHub API: автоматическое чтение, общая запись и чтение второй сессией, одновременные правки разных пациентов, конфликт одного пациента, отказ в записи, большие raw-файлы, отказ от публичного репозитория, общие замечания и запрет связи. Реальная авторизация браузера требует ключа владельца.

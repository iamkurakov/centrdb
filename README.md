# ЦДБ — рабочий навигатор

Статический интерфейс GitHub Pages и данные в закрытом репозитории `iamkurakov/centrdb-data`. Python, VPS и SQLite для этой версии не нужны. Предыдущая серверная версия доступна в истории Git.

## Реализовано

- Трёхслойный маркетинговый план и инструкции.
- Чтение закрытого HTML-отчёта через GitHub API, показ в изолированном iframe.
- Общие задачи команды с сохранением в `workspace.json` и историей коммитов.
- Проверка закрытости репозитория, обработка конфликтов по SHA, отсутствие токена в исходниках и постоянном хранилище браузера.
- Относительные пути для размещения в `/centrdb/`.

[Настройка Pages и персонального доступа](SETUP.md).

## Доступ

Текущая версия предназначена руководству. Все участники одного репозитория имеют доступ ко всем его данным. Четыре независимые роли центра пока не реализованы. Для разграничения без отдельного серверного посредника нужны разные репозитории и права GitHub. Не выдавайте подрядчикам доступ к `centrdb-data`.

## Аналитика

В закрытом хранилище размещён рабочий отчёт с расходами за два месяца, вместимостью и ограничениями. Исторические графики сохранены, модель полностью не пересчитана. Недоступные сведения по ФОТ, графикам и условиям курсов приняты как ограничения, их получение не блокирует работу. Историческую атрибуцию рекламы не восстанавливаем. Полная маржа, прибыль и безубыточность остаются недоступными как факты.

Файл допущений хранится отдельно, но не обновляет графики автоматически. Неизвестные параметры не заменены нулями. Не следует выдавать эту версию за завершённый полный расчёт юнит-экономики.

## Проверки

Node.js 18+:

```bash
node --test tests/github-store.test.js
```

Проверяются UTF-8/Base64, отказ от публичного хранилища, SHA/ветка при записи, отсутствие автоматической перезаписи конфликтов и очистка токена. Браузерная проверка с персональным токеном и внешняя публикация требуют соответствующего доступа.

Локальный просмотр интерфейса:

```bash
python3 -m http.server 8080
```

Открыть http://localhost:8080 . Python здесь нужен только как локальный просмотрщик, а не рабочий сервер или хранилище.

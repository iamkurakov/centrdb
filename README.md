# ЦДБ — экономика и памятки для команды

- `index.html`: три ссылки на основные разделы.
- `economics.html`: подробный отчёт; расчёты при этой переработке не менялись.
- `marketing.html`: две основные задачи — отзывы и причины пауз; 13 ситуаций, по два варианта текста; копирование, короткая проверка перед разговором, ответы на причины пауз и отзывы.
- `clients.html`: восемь исторических групп, критерии выбора в 1С и переходы к нужным скриптам. Обязательной загрузки данных нет.
- `playbook.js`, `playbook.css`: переключение вариантов, копирование и оформление памяток.
- `help.js`, `help.css`: пояснения по кнопке «?»; новые блоки используют `data-help-title` и `data-help-text`.

## Работа менеджера

Пациентов, телефоны, историю контактов и результаты ведут в 1С. Числа на сайте — из отчёта на 21.10.2026, не сегодняшний поимённый список. Новые памятки не получают данные из 1С и не отправляют сообщения. Галочки относятся к одному разговору и сбрасываются после перезагрузки или кнопкой.

Просим реальных пациентов о честном отзыве без заданной оценки, готового отзыва от их имени или оплаты. Постоянные — первая группа проверки, а не отбор только положительных мнений. Жалобы разбираются независимо от приглашения оставить отзыв. В скриптах нужно заменить данные в квадратных скобках. Проверенные ссылки на карточки центра ответственный берёт из кабинетов площадок.

## Прежние записи

`marketing-results.html` и `clients-data.html` сохраняют прежние рабочие страницы. Ранее сохранённые localStorage / IndexedDB не очищаются. Старые формы доступны через свёрнутую ссылку внизу соответствующего раздела. Их заполнение не требуется для работы с новыми памятками.

## Проверка

`node --check playbook.js` и `node --check help.js`.
`node --test hub-tests/core.test.mjs` проверяет правила прежней локальной базы. Новый интерфейс проверяется в браузере: две версии каждого скрипта, клавиатурное переключение, копирование, сброс галочек, подсказки и переход из группы к раскрытому скрипту.

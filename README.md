# ЦДБ — экономика и работа с базой

Экономика сохранена. marketing.html и clients.html содержат девять направлений, скрипты, списки и карточки. Сайт работает без ChatGPT и регистрации.

«База и резервные копии»: импорт JSON/CSV, режимы demo/real, экспорт, восстановление и отмена восстановления. Данные сохраняются в IndexedDB браузера, а не в публичном репозитории. Общей синхронизации между компьютерами и автоматической связи с 1С или GitHub нет.

Реальные пациентские файлы, копии, токены и ключи нельзя помещать в публичный репозиторий. Скрипты поставляются с сайта, CSP connect-src none запрещает их сетевые соединения.

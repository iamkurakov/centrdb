# ЦДБ: экономика, RFM и общая работа команды

Сайт: https://iamkurakov.github.io/centrdb/

994 постоянных ID; RFM для 971 ID, 23 без оплат. Экономика, сегментация и списки направлений остаются открытыми. Рабочая история не публикуется вместе с сайтом.

## Общая работа

`cloud-setup.html` — однократное техническое подключение владельца и выдача именных доступов. До подключения аналитика доступна, но назначения неизвестны и запись рабочих результатов заблокирована. Сайт не подменяет общую запись локальным сохранением.

После подключения все назначения, результаты контактов, чек-листы, возражения, следующие действия, даты и обратная связь записываются в закрытый `iamkurakov/centrdb-data`, файл `work/patient-workspace.json`. Каждый менеджер получает личную ссылку и пароль, без ввода API-ключа в повседневной работе.

Один ID закрепляется за одним ответственным сразу для всех направлений. Есть набор 20 свободных ID, фильтры «Мои ID», «Свободные», «За коллегами», последний контакт и общая история. Руководитель может передать ID и управлять именными доступами. Назначение не истекает автоматически.

Чужую карточку нельзя сохранить. При конфликте версий текст остаётся в форме. Изменения разных ID объединяются поверх свежей версии GitHub; запись подтверждается только после успешного сохранения. Общий статус обновляется каждые 15 секунд и перечитывается перед изменением. При потере связи новые операции блокируются.

После освобождения ID новый ответственный не может взять его в течение 24 часов после контакта и до согласованной даты. Руководитель может явно передать ID; предупреждение об истории сохраняется. Это организационная защита от случайных повторных звонков, не система автоматической телефонии.

Прежние локальные записи переносятся после первого входа. Уже существующая общая версия не затирается; история добавляется без повторения ID записей. Локальная копия остаётся для сверки.

## Исходники и проверки

`demo-source/coded-workspace.tsx` — интерфейс; `coded-store.ts` — подключение и сеанс; `shared-core.ts` — назначения, версии и история; `cloud-client.ts` — Contents API и условная запись по SHA; `cloud-crypto.ts` — именные ссылки; `cloud-setup.tsx` — выдача доступов; `legacy-import.ts` — перенос прежних записей.

`npm run build:workspace` пересобирает рабочий интерфейс и страницу владельца. `npm run test:shared` проверяет четыре одновременных менеджера, конфликты, повторы после потери ответа, перенос, запреты связи и личные ссылки. `npm run test:rfm` проверяет неизменённую сегментацию.

Данные аналитики обновляются новой согласованной выгрузкой из 1С. Общие результаты контактов не меняют исходный RFM. Схема доступа, ограничения и однократное подключение описаны в `SETUP.md` и `SHARED_WORK.md`.

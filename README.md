# ЦДБ — открытый маркетинговый раздел

https://iamkurakov.github.io/centrdb/

Маркетинг открывается без регистрации, пароля и API-ключа. Девять направлений содержат инструкции, два сценария, возражения, чек-листы и локальную обратную связь. Публичные сводные размеры групп рассчитаны по исходной базе на 02.11.2026. Индивидуальные карточки — 36 вымышленных примеров. Результаты и замечания сохраняются в IndexedDB браузера и не синхронизируются между компьютерами.

Реальные ФИО, телефоны, индивидуальная история, токены и пароли в публичную сборку не включены. Общая приватная база centrdb-data не запрашивается этим сайтом. Предыдущие персональные данные, загруженные пользователем локально, остаются только в его браузере. Настройки локальных записей доступны отдельно.

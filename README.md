# ЦДБ — экономика, RFM и маркетинг по ID

Сайт: https://iamkurakov.github.io/centrdb/

Экономика сохраняет прежние расчёты; вводный блок «Как пользоваться отчётом» удалён.

Клиентская база содержит 994 постоянных пятизначных кода из 1С. Для 971 ID рассчитаны RFM-баллы. 23 ID без положительных оплат выделены отдельно. ФИО, телефоны, точные индивидуальные даты и суммы в публичные данные не включены. RFM-сегменты не пересекаются; списки девяти маркетинговых направлений могут пересекаться. Переходы между разделами сохраняют ID.

RFM: срез 02.11.2026, оплаты и возвраты 01.10.2025–21.10.2026. F — количество календарных дней с положительными оплатами, не число договоров; M — поступления минус возвраты. Критерии и все 27 сочетаний доступны в клиентской базе. Метод и сверка — RFM_METHOD.md.

Комментарии, чек-листы и история сохраняются в IndexedDB этого браузера, отдельно от прежних демонстрационных данных. Они не синхронизируются между компьютерами и не отправляются в публичный репозиторий. RFM не меняется от комментария менеджера. Автоматического обновления из 1С нет.

Исполняемая сборка не обращается к API GitHub и не требует ключей. Данные и функции размещены в GitHub Pages; сторонний хостинг не используется.

## Исходники

`demo-source/entry.tsx` → `coded-workspace.tsx`; `coded-store.ts` хранит локальные записи. `coded-base.json` содержит только публичный набор полей. `build-coded-data.mjs` пересчитывает баллы и группы и отбирает поля по белому списку. Полная исходная база хранится в закрытом centrdb-data и не включается в этот репозиторий.

Проверка RFM: `node --test demo-source/coded-data.test.mjs`.

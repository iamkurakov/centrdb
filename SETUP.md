# Использование

Открыть clients.html для RFM или marketing.html для работы по направлениям. Вход и ключ не требуются.

ID — постоянный код клиента из 1С с ведущими нулями. Поиск, сегменты RFM и направления маркетинга используют один набор из 994 ID. Из таблицы RFM можно перейти в конкретное направление с отбором по ID. В карточке маркетинга есть обратная ссылка на RFM этого ID. Контакт находится в 1С по этому коду.

Имя сотрудника — подпись локальной записи, а не учётная запись. Сохранение подтверждается после записи в IndexedDB; прежняя история остаётся. При одновременном изменении одной карточки в другой вкладке устаревшая версия не перезаписывается. Общей синхронизации между устройствами нет.

После `npm install` выполнить `npm run build:workspace`, выполнить `node --test demo-source/coded-data.test.mjs` и проверить даты среза в интерфейсе.

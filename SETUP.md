# Текущая версия ЦДБ

Сайт открыт без токенов и авторизации. На главной три ссылки: экономика, маркетинг, клиентская база. Права доступа — отдельный следующий этап, текущая версия их не имитирует.

Публикация: существующий GitHub Pages, ветка main, корень. Python-сервер для работы сайта не нужен.

Маркетинговые поля сохраняются в браузере. Для переноса — «Выгрузить результаты» и загрузка JSON на другом устройстве.

Клиентская база хранит только локальные записи через IndexedDB. В начале показаны исторические сводные группы на 21.10.2026, не реальные индивидуальные карточки. Для работы скачать CSV-шаблон, заполнить согласованный одинаковый период покупок/оплат и загрузить CSV или JSON. На странице есть описание формата и правил RFM. Новая загрузка пересчитывает сегменты. Результат звонка не меняет дату последнего визита; после нового визита/покупки нужен обновлённый файл.

Сохраняйте резервные выгрузки. Очистка браузера удаляет локальные записи. В файлах клиентской базы не должно быть ФИО, телефонов и медицинских карт. Код не отправляет их на GitHub.

Автоматической связи с 1С, общей синхронизации между устройствами и настроенных ролей в этой версии нет.

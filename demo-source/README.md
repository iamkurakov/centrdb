# Демонстрация без регистрации

36 вымышленных карточек. Реальных ФИО, телефонов, посещений и оплат пациентов здесь нет. Нельзя добавлять исходную пациентскую базу в этот публичный репозиторий.

Редактирование результатов, история и замечания сохраняются в localStorage текущего браузера. Это демонстрация интерфейса, общего серверного хранилища в этой версии нет. Импорт реальных пациентов не предусмотрен. Экономика остаётся на своей прежней странице.

Для пересборки нужны react, react-dom, esbuild. Команда build.mjs использует установленный esbuild из зависимостей wrangler; в автономном проекте можно заменить импорт на прямой esbuild. Скопировать demo.js и demo.css в корень сайта.

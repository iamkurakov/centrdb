# Прямой GitHub-режим

github-client.ts — HTTPS, токен только в Authorization, UTF-8/base64, raw-ответы больших файлов. github-work.ts — загрузка исходной базы, общий журнал, сравнение версий карточек, повтор при изменении другого пациента. service.ts — сессия вкладки и переключение транспорта. connection.tsx — первый вход. demo-workspace.tsx — рабочий интерфейс. Локальный импорт сохранён как дополнительный режим.

Публичный CSP разрешает соединения только с https://api.github.com. Нет внешних скриптов и аналитики. Общая база не копируется в IndexedDB или localStorage. Состояние в GitHub хранит версии карточек, последние действия по направлениям, историю контактов, замечания, автора и GitHub login. Имя сотрудника задаётся на входе; это не независимая проверенная учётная запись.

Реальные данные и credentials отсутствуют в публичной сборке. Для проверки: node --test demo-source/github-check.mjs (пути в тесте рассчитаны на рабочий каталог автора).

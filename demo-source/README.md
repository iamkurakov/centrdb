# Открытая версия

entry.tsx → connection.tsx → demo-workspace.tsx. connection.tsx сразу открывает интерфейс и очищает прежнюю сессию подключения. service.ts использует только локальное хранилище demo-store.ts. public-summary.json содержит агрегаты без индивидуальных данных. github-client.ts и github-work.ts — неиспользуемые архивные модули, в актуальную сборку не включены.

# Локальная база

36 вымышленных карточек используются до загрузки реального файла. Данные режимов хранятся отдельно в IndexedDB centrdb-client-workspace. Импорт проверяется до записи, комментарии и история сохраняются по коду пациента. Отсутствующие в новом файле карточки помечаются, не удаляются. Группы и RFM считаются на дату среза. Если нужных полей нет, группа не выдумывается. Задачу можно выбрать вручную.

JSON: {asOf:"2026-11-02",patients:[{id,name,phone,lastVisit,lastPayment,visits,purchases,paid,refund,net,consultations,training,packageLeft}]}. purchases означает дни с оплатами, даты ГГГГ-ММ-ДД. CSV UTF-8: обязательные колонки Код;ФИО;Телефон. Дополнительные колонки описаны в подсказке загрузки. XLS/XLSX напрямую не поддерживаются.

Резервная копия содержит базу и историю. Восстановление заменяет один режим, прежний набор остаётся для отмены. Запись контакта использует транзакцию и проверку версии карточки и поколения набора. Имя автора вводит сотрудник, это не подтверждённая учётная запись. Прямой обмен с GitHub API не включён; закрытый centrdb-data может служить источником файлов при ручной передаче.

Проверены дубли, даты, CSV, неизвестные поля, сохранение заметок и карточек при обновлении, валидация копии и подготовленная база 994 карточек. В браузере на синтетических данных проверены импорт, запись контакта, перезагрузка, скачивание и восстановление копии.
